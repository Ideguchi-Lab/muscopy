Muscopy documentation
=====================

Muscopy provides microscopy analysis utilities for quantitative phase imaging,
digital holography, optical diffraction tomography, intensity diffraction
tomography, phasor analysis, and related workflows.

Use the gallery for executable examples and the module reference for API details.
