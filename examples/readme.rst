Muscopy Examples
================

Start with :doc:`qpi_reconstruct` for off-axis phase reconstruction from a sample
hologram and its reference. The examples generate synthetic inputs in memory
using the helpers in ``muscopy.example_holograms`` and ``muscopy.example_mlb``.
Run ``muscopy-generate-hologram holograms.npz`` to save the standard QPI input
pair and its microscope parameters.
