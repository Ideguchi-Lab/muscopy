Muscopy Examples
================

Here are some examples of how to use the Muscopy library.

Available Examples
------------------

* **qpi_reconstruct.py** - Demonstration of basic Quantitative Phase Imaging (QPI) reconstruction using off-axis digital holography
* **multiplexed_qpi.py** - Example of multiplexed QPI reconstruction with demultiplexing
* **inline_dh_demo.py** - Comprehensive demonstration of Inline Digital Holography (IDH) with twin-image suppression
* **idh_practical_example.py** - Practical IDH example with realistic noise, background correction, and parameter optimization
* **shot_noise_calculation.py** - Shot noise analysis example
* **unwrap_phase_demo.py** - Phase unwrapping demonstration
